## 3. 端点映射机制（逆向结论）

Q7 前端（webpack + Vue + vuex）的数据层：

```
页面 JS:  $store.dispatch("multiGets", ["deviceinfo","wlanmode","backhaul","wlanintelligent"])
                │
                ▼
端点名转换:  function a(t){var n=c[t];return n?/^\//.test(n)?n:"/api/"+n:t}
                │          └─ 映射表 c：短名 → "system/xxx" 等相对路径
                ▼
HTTP:     GET /api/<映射路径>   （无映射的短名直接作为路径）
```

- 映射表共 **198 个短名→路径对**（已固化到 `q7_map_final.json`）
- 命名空间分布：`ntwk` 98、`system` 51、`openee`(插件) 11、`app` 13、`device` 5、`hilink` 5、`sdcard` 4、`usbstorage` 3、`bsp` 1、`language` 1
- 免登录行为：所有需认证端点统一返回 **404**（防枚举），探测必须登录后进行

## 5. 认证协议（登录页逆向，供探测脚本核对）

登录端点三步（SCRAM 风格，与项目 crypto.py 一致）：

```
1. GET  api/system/user_login_nonce   → 服务器下发 salt + nonce
2. POST api/system/user_login_proof   → 客户端证明（sha256 链）
3. POST api/system/user_login         → 换取 SessionID_R3 cookie + csrf
```

- 会话 cookie：`SessionID_R3`
- 写请求需携带动态 `csrf_param/csrf_token`（每次响应刷新）
- 同一账号多端登录互踢（`Too_Many_user`）——集成已有处理
